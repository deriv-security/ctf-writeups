# CyberQ Hackathon 2025

**Website**: https://cyberq.ctf.ae/  
**Dates**: October 20-21, 2025 (Online Qualifiers) | November 26-27, 2025 (Finals)  
**Location**: Online + ADNEC, Abu Dhabi (Finals)  
**Prize Pool**: AED 100,000  
**Organizers**: Technology Innovation Institute (TII) & Cyber Security Council (CSC)

## About

The CyberQ Hackathon is the ultimate challenge in cybersecurity, featuring next-gen cryptography, post-quantum algorithms, and AI vulnerabilities. This competition tests skills in:

- Cybersecurity
- Post-Quantum Cryptography
- Cryptanalysis
- AI Security & Vulnerabilities
- Advanced Cryptographic Challenges

## Challenge Categories

### Cryptography (`crypto/`)
Advanced cryptographic challenges including post-quantum algorithms, cryptanalysis, and modern encryption schemes.

### AI/ML Security (`ai-ml/`)
Challenges focused on AI security vulnerabilities, machine learning exploits, and adversarial attacks.

## Writeup Structure

Each challenge directory contains:
- **WRITEUP.md** or **README.md**: Detailed explanation of the challenge and solution approach
- **solve.py** (or similar): Working solution script
- **flag.txt**: The captured flag
- Additional files: Challenge files, data, or supplementary materials
